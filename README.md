# 🔐 Flutter Firebase Authentication  

This repository contains **Flutter projects** that demonstrates how to integrate **Firebase Authentication** into a Flutter app.  
It covers the **essential authentication features** using Firebase, providing a solid starting point for apps that require secure user login and account management.  

---

## 📌 Features Implemented
- **User Authentication**  
  - Sign Up (Email & Password)  
  - Login (Email & Password)  
  - Logout
  - Forgot Password
- **Firebase Integration**  
  - Configured Firebase for Android & iOS  
  - Connected Flutter project with Firebase Console  
- **Authentication State Handling**  
  - Auto-login for existing users  
  - Redirect based on login state  
- **Error Handling**  
  - Displays messages for invalid credentials, weak passwords, etc.  

---

## 🛠️ Tech Stack
- **Framework:** Flutter  
- **State Management:** Provider (or setState depending on implementation)  
- **Backend:** Firebase Authentication
